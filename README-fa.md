# bidi-skills

**ایجنت‌های هوش مصنوعی متن RTL خراب می‌نویسند. این اسکیل‌ها درستش می‌کنند.**

اسکیل‌ها + یک چکر قطعی که به Claude Code، Cursor، Codex و بقیه ایجنت‌ها یاد می‌دهد محتوای راست‌به‌چپ و دوزبانه را درست تولید کنند — فارسی، عربی، اردو، عبری. بدون هیچ وابستگی.

## مشکل

از هر مدلی بخواهید محتوای فارسی یا عربی بنویسد، هربار همان خرابی‌ها را تحویل می‌گیرید:

| ❌ چیزی که ایجنت‌ها تولید می‌کنند | ✅ درست | چرا مهم است |
|---|---|---|
| می شود (با فاصله) | می‌شود (نیم‌فاصله) | پیشوند باید با U+200C بچسبد؛ فاصله هم غلط خوانده می‌شود هم جستجو را خراب می‌کند |
| کتاب ها | کتاب‌ها | پسوند جمع به‌صورت یک کلمه جدا افتاده |
| كتاب / کتاب با ك ي عربی | کتاب با ک ی فارسی | کدپوینت‌های متفاوت — جستجو، مرتب‌سازی و فونت بی‌صدا خراب می‌شوند |
| `ihr = ریشه + t` با bidi جابه‌جا شده | فرمول به‌صورت یک نوار LTR حفظ شده | رندر دوزبانه، عملگرها و توکن‌ها را به‌هم می‌ریزد |
| 123 کنار ۴۵۶ | یک سیستم رقمی در هر سند | رقم‌های قاطی، هم بد دیده می‌شوند هم ناسازگار پارس می‌شوند |

نگه‌دارنده‌های محتوای RTL این‌ها را برای همیشه با دست درست می‌کنند. هیچ پک اسکیلی برای این کار نبود — در اکوسیستمی با صدها اسکیل انگلیسی‌محور، RTL (حدود ۶۰۰ میلیون گوینده) هیچی نداشت. حالا دارد.

## چه چیزی داخلش است (نسخه ۰٫۱)

- **`skills/rtl-text`** — یک اسکیل ایجنت با قوانین تولیدی: چسباندن با نیم‌فاصله، کدپوینت فارسی در برابر عربی، مدیریت جزیره‌های LTR برای کد/فرمول/URL، انضباط رقم و علائم، قوانین چیدمان RTL (تراز، ارتفاع خط، بدون letter-spacing).
- **`skills/rtl-text/scripts/bidi_check.py`** — یک چکر بدون وابستگی که فایل‌های متنی را اسکن می‌کند و خرابی‌ها را به‌صورت قطعی علامت می‌زند، با امتیاز bidi صفر تا صد:

```bash
$ python3 bidi_check.py article.md
[ERROR  ] article.md:3 ZWNJ_SPACE: «می …» uses a space; Persian prefixes join with ZWNJ
[ERROR  ] article.md:5 PLURAL_SPACE: Plural suffix split by a space; join with ZWNJ: «کتاب‌ها»
[WARNING] article.md DIGIT_MIXING: Mixed digit systems in one document

Bidi score: 76/100 · 3 finding(s)
```

## نصب در Claude Code

```bash
git clone https://github.com/mohammad-abbasi-sh/bidi-skills
cp -r bidi-skills/skills/rtl-text ~/.claude/skills/
```

بعد مثل همیشه محتوای فارسی/عربی بنویسید — وقتی متن RTL وسط باشد اسکیل لود می‌شود و ایجنت قبل از تحویل، خروجی‌اش را با `bidi_check.py` خودش چک می‌کند.

برای Claude.ai: زیپ اسکیل را از صفحه release دانلود کنید و در Settings ← Capabilities ← Skills آپلود کنید.

## نصب در Cursor (و بقیه ایجنت‌ها)

هیچ‌چیز اینجا مخصوص Claude نیست — قوانین متن ساده‌اند و چکر هم پایتون ساده است.

- **Cursor:** فایل `cursor/rtl-text.mdc` را در `.cursor/rules/` پروژه‌تان کپی کنید — جزئیات، از جمله چکر در ترمینال Cursor، در [cursor/README.md](cursor/README.md).
- **Windsurf / Cline / Continue / ایجنت‌های عمومی:** متن قانون (یا `skills/rtl-text/SKILL.md`) را در فایل قوانین یا system prompt ابزار بچسبانید.

## نقشه راه

- `ar-text` / `ur-text` / `he-text` — عمق قانون برای هر زبان (انضباط ة/همزه در عربی، نکته‌های نستعلیق اردو، نیقود و سرنام‌ها در عبری)
- `rtl-ui-audit` — اسکن HTML/CSS برای اشتباه‌های `dir`، تراز و ویژگی‌های منطقی
- سرور MCP که `bidi_check` را به‌عنوان ابزار در اختیار هر کلاینت MCP می‌گذارد
- قوانین بیشتر برای چکر، بر اساس گزارش‌های خرابی واقعی (issueها خوش‌آمدند)

## اصول

- **قطعی، آنجا که مهم است.** قوانین متن‌اند، ولی اعتبارسنجی کد است — ایجنت باید چکر را اجرا کند، نه اینکه حسی حدس بزند.
- **زاده تولید واقعی.** این قوانین از انتشار روزانه محتوای واقعی فارسی آمده‌اند، نه از یک برگه مشخصات.
